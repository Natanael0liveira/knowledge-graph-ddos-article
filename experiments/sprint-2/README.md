# Sprint 2: calibrated synthetic generator

This stage holds the generator behind every result on generated traffic, and the
distributions it samples. [`scripts/generator.py`](scripts/generator.py) writes one
JSON line per HTTP request. Legitimate sessions are sampled from benign CICIDS2017
sessions, and a campaign adds K attackers. In stealth mode the attackers' sessions
come from the same benign distributions, so only what sessions share (JA4,
endpoint, /24) sets the campaign apart. The paper's scenarios are generated by
sprint-6 targets that call this generator. The targets here fit the distributions,
generate the original A/B/C sweep and run the KS check.

## In the paper

- **Section IV-A.** K = 50 and 1,000 in stealth mode on the attacked service, Zipf
  α = 1.5 and M = 25 stacks by default, and an adversarial mode. The KS distances
  (D = 0.002 and 0.003) "check only the sampler". Attackers start within the first
  30 s.
- **Appendix B.** Request counts come from all 322,658 benign CICIDS2017 sessions
  and durations from the 40,351 with two or more requests. The default pool holds
  2,000 benign fingerprints.
- **Where the paper's scenarios come from.** Sprint-6 `make canonical`, `realistic`
  and `rule` call `generator.py --config configs/scenario_stealth.yaml` with
  `--param` overrides of `K`, `benign_ja4_zipf_alpha`, `botnet_ja4_stacks` and
  `botnet_ja4_adversarial`. `symbolic`, `drift`, `baselines`, `unseen-synth` and
  `cross-m` read what those runs cached. The shared mode (stacks from the profile's
  tail) has no generator parameter: sprint-6 `unseen_synth.py` renames the stacks
  of cached scenarios.
- **Not in the paper:** the A/B/C sweep, which feeds no later stage.

## Inputs

- `$DATA_ROOT/processed/sessions/cicids2017.parquet` from [sprint 1](../sprint-1/),
  labeled with `label_cicids2017.py`. `calibrate`, `validate` and
  `calibrate_flow.py` read its BENIGN sessions.
- [`distributions/`](distributions/), the committed copy of the calibration. It is
  derived from CICIDS2017 and stays under that dataset's terms
  ([NOTICE](../../NOTICE)). Sprint 6 reads it (`DIST ?= ../sprint-2/distributions`);
  sprints 3 and 4 read the drive copy in `$DATA_ROOT/synth/distributions/`.

| File | What the generator draws from it | Written by |
|---|---|---|
| `session_requests.json` | Requests per session (322,658 benign sessions) | `make calibrate` |
| `session_duration.json` | Duration of the sessions with two or more requests (40,351) | `make calibrate` |
| `arrival.json` | Gap between session starts | `make calibrate` |
| `flow_{fwd,bwd}_{bytes,pkts}.json` | Bytes and packets per request | `calibrate_flow.py` |
| `ja4_users.json` | Benign JA4 (39 lab fingerprints), only when `benign_ja4_pool` is 0 | `make calibrate` |
| `endpoints.json` | Benign destination ports, only when `benign_same_service` is false | `make calibrate` |
| `_metadata.json` | Source file and label counts | `make calibrate` |

- [`configs/`](configs/). `scenario_stealth.yaml` is the base of every later stage.
  `scenario_A/B/C.yaml` drive the original sweep. `scenario_hard.yaml` produced
  sprint-4's `weights_hard.json`. `scenario_realistic.yaml` and
  `scenario_adversarial.yaml` are reference files that no target reads.

`--param name=value` overrides any parameter, and `--seed` (default 42) is a
command-line option. "Default" applies when the config omits the key. "Paper" is
`scenario_stealth.yaml` with the sprint-6 overrides.

| Parameter | Default | Paper | Meaning |
|---|---|---|---|
| `K` | 1 | 50, 1000 | Attackers, each a distinct origin; `K=0` gives an attack-free run |
| `legitimate_sessions` | 500 | 1000 | Legitimate sessions generated |
| `stealth` | false | true | Attacker sessions sample the benign distributions; `attack_variant`, `window_s` and `coordination_temporal_jitter` are then ignored |
| `attack_variant` | `slowloris` | ignored | `slowloris`, `slow_body`, `slow_read`, `hulk` or `goldeneye` timing and volume, outside stealth mode |
| `window_s` | 300 | ignored | Cap on an attacker session outside stealth mode, in seconds |
| `coordination_ja4_share` | 1.0 | 0.9 | Share of attackers on the botnet's stacks; the rest get one-off fingerprints |
| `coordination_identity_reuse` | 0.0 | 0.2 | Share of attackers that reuse one identity token; no scope or feature reads it |
| `coordination_temporal_jitter` | 0.0 | 0.3, ignored | Timing noise outside stealth mode |
| `asn_dispersion` | 1 | 2000 | Size of the attackers' ASN pool, drawn from the 12 documentation ASNs 64500–64511 |
| `prefix_dispersion` | 1 | 2000 | Distinct /24 prefixes the attackers draw from |
| `benign_same_service` | false | true | Legitimate users reach the attacked endpoint, 10.0.0.1:443 |
| `benign_ja4_pool` | 0 | 2000 | Size of the benign fingerprint vocabulary |
| `benign_ja4_zipf_alpha` | 0 (uniform) | 1.5 | Zipf exponent of benign fingerprint popularity |
| `botnet_ja4_stacks` | 1 | 25 | TLS stacks (M) that the botnet's shared fingerprints spread over, uniformly at random |
| `botnet_ja4_adversarial` | false | false; true in the adversarial runs | The stacks become the M most common benign fingerprints |

## Run

| Target | What it does | Writes |
|---|---|---|
| `help` | Lists the targets; works without `.env` | |
| `calibrate` | Fits five distributions to Sprint 1's BENIGN sessions; the flow files need `calibrate_flow.py` (below) | `$DATA_ROOT/synth/distributions/` |
| `scenario-A` | Original sweep, `scenario_A.yaml`: K = 1, 30 seeds | `$DATA_ROOT/synth/scenarios/A/` |
| `scenario-B` | `scenario_B.yaml`: K = 10, 50 and 100, 30 seeds each | `$DATA_ROOT/synth/scenarios/B/` |
| `scenario-C` | `scenario_C.yaml`: K = 1,000 and 10,000, 30 seeds each | `$DATA_ROOT/synth/scenarios/C/` |
| `validate` | KS test of the legitimate sessions in `SYNTH` against Sprint 1's BENIGN sessions, on duration and requests per session; `SYNTH` is a directory of generator `.jsonl` files, `$DATA_ROOT/synth/scenarios/A` by default; prints the result | |
| `clean` | Removes `$DATA_ROOT/synth/scenarios/{A,B,C}` and keeps the distributions | |

Without a target:

```bash
# Bytes and packets per request (flow_*.json), which stealth mode samples
../.venv/bin/python scripts/calibrate_flow.py \
  --benign ../data/processed/sessions/cicids2017.parquet --out-dir ../data/synth/distributions

# One canonical scenario (K = 1,000, seed 1), then its sessions
../.venv/bin/python scripts/generator.py --config configs/scenario_stealth.yaml --seed 1 \
  --distributions distributions --param K=1000 --param benign_ja4_zipf_alpha=1.5 \
  --param botnet_ja4_stacks=25 --out /tmp/k1000_seed1.jsonl
../.venv/bin/python scripts/synth_to_sessions.py --jsonl /tmp/k1000_seed1.jsonl \
  --out /tmp/k1000_seed1.parquet

# The same-service check on hand-made distributions; needs no data
../.venv/bin/python scripts/sanity_same_service.py
```

`../data` is the symlink to `DATA_ROOT` that `setup-data-storage.sh` creates.
`validate_synth.py --out FILE` also saves the KS distances as JSON.

## Results

[`results/ks_validation.json`](results/ks_validation.json) compares 60,000
legitimate sessions of the sprint-4 cache (`sprint4_realistic_work`) with the
322,658 benign CICIDS2017 sessions. It gives D = 0.0027 for duration (p = 0.84) and
D = 0.002 for requests per session (p = 0.99). The generator samples these very
distributions, so the check covers the sampler only (Section IV-A).

The lab JA4 distribution holds 39 fingerprints, the most common at 52.7% of the
benign sessions with a JA4 ([`distributions/ja4_users.json`](distributions/ja4_users.json)).
The paper sets fingerprint popularity from a production measurement: the most
common fingerprint carries 38.4% of requests, consistent with α = 1.5
(Section IV-A).

## Caveats

- `make calibrate` writes no flow distributions. Without `calibrate_flow.py` the
  generator logs a warning and gives every request the same bytes and packets, so
  the volume features only repeat the request count.
- `results/ks_validation.json` has no producer in the repository. Its fields differ
  from what `validate_synth.py --out` writes, and that script reads only `.jsonl`
  files, while the sprint-4 cache keeps `.parquet` files only (`run_sprint4.py`
  deletes each `.jsonl` after conversion). `make validate SYNTH=../data/synth/sprint3`
  runs the same check on sprint 3's stealth scenarios, which keep their `.jsonl`.
- Attackers start within the first 30 s (`uniform(0, 30)`), so a campaign is a
  median 34–45% of the origins in the windows it overlaps and 50% of the alarm's
  cluster (Section IV-A). Benign starts pack early: session i starts at i times a
  gap drawn from `arrival.json` (median 0 s, floored at 0.01 s). Appendix E spreads
  them over 60 min.
- Attacker ASNs come from 12 documentation values, whatever `asn_dispersion` says.
  No scope reads the ASN: a shared ASN is specified but not exercised (Appendix A).
- The comments of `generator.py`, `scenario_realistic.yaml` and
  `scenario_adversarial.yaml` call the lab head (52.7%) the calibrated
  distribution. The paper calibrates α on the production measurement (38.4%).
